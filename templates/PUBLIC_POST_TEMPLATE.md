# Honest Technical Announcement Template

Use this format when announcing an early-stage technical system. Replace every
placeholder and delete sections that do not apply.

## What we built

We built **[component / subsystem / integrated prototype]** for **[bounded
problem]**.

## Current maturity

Current status is **[concept / prototype / TRL X]**, referring specifically to
**[the component, subsystem, or integrated system]**. This does not imply that
the full platform is at the same maturity.

## What we tested

- **Evidence class:** [E0–E4]
- **Test setting:** [lab / relevant environment / operational environment]
- **Sample count:** [N]
- **Metric:** [metric and unit]
- **Observed result:** [bounded result]
- **Pass criterion:** [pre-declared criterion]
- **Truth source:** [independent / system-internal / not applicable]

## Conditions and limits

The result applies under **[conditions]**. Known limitations include:

- [limitation]
- [limitation]
- [next untested condition]

## What this does not prove

This result does not establish **[field readiness / universal immunity /
operational effectiveness / a system-level claim]**.

## Next gate

The next validation step is **[specific test or integration milestone]**.

Technical questions are welcome. Proprietary implementation details remain
protected; envelope-level conditions and results are reported where possible.
